# 首頁主視覺

`dist/assets/ui/home-forest.png` 為使用者於 2026-10-22 提供的首頁圖片原檔（1739 × 904），直接複製保存，未重新生成或修改圖中文字。

`index.html` 的原生按鈕覆蓋圖中「開始遊戲」與「設定」木牌，提供滑鼠、觸控及鍵盤操作。圖片與點擊區域共用同一縮放座標；橫向畫面滿版，直向畫面限制縮放以保留完整中央標題，周圍以模糊背景延伸。設定視窗、減少動態偏好與選關往返維持可用。

驗證：桌面首頁、兩個木牌點擊、選關返回首頁、鍵盤 Enter 開啟設定與 Escape 關閉、390 × 844 直向顯示（無橫向溢出，按鈕約 212 × 55 px）。

驗收截圖：`home-desktop.png`、`home-mobile.png`。

## 首頁設定視窗（2026-10-22）

首頁採用現有 `assets/ui/settings-kit/` 的木框、羊皮紙、木牌、音量滑桿及勾選框素材，透過共用 `settings-panel.js` 的 home 模式呈現。首頁主操作為「開始遊戲」（進入選關）與「返回首頁」（關閉視窗）。原有初始速度與森林動態保留在「其他設定」。音量調至 0 可靜音，音樂通道沿用現有設定；目前沒有新增背景音樂。

已實測音效／音樂數值更新與重新載入保存、顯示選項保存及首頁／選關同步、進入選關、返回首頁、390 × 844 下的其他設定展開。預覽為 `settings-desktop.png` 與 `settings-mobile.png`。

後續調整：依使用者要求移除整個「其他設定」區塊（初始速度、森林動態與說明文字），主操作按鈕緊接顯示選項。已儲存的偏好仍沿用。
