# Boss 哥布林隊長／戰吼

使用內建 imagegen，依使用者提供的紅披風、骷髏戰旗哥布林隊長参考圖繪製。完整角色與光環提示詞在 `prompts.txt`；原稿為 `source.png`、`aura-source.png`。

成品在 `dist/assets/boss/`：

- `boss_goblin_captain.png`：1296×48，27 格；每格 48×48，anchor (24,44)。Idle(4) | Walk(4) | Attack(4) | Warcry(6) | Hurt(3) | Death(6)，起始格 0、4、8、12、18、21。
- `goblin_warcry_aura.png`：192×48，4 格；每格 48×48，anchor (24,34)，獨立腳下光環，可循環疊加於任何受增益單位。
- `goblin-captain.json`、`goblin-warcry-aura.json`：固定切圖座標規格。

RGBA 真透明、透明像素 RGB 歸零、零間距；角色以共同等比例縮放打包。預設向右，可翻轉向左。重建時在可載入 sharp 的 Node 環境執行 `node tools/pack-goblin-captain.cjs`。

`/test` →「Boss 素材」可放置隊長與獨立光環；「載入戰吼範例」同時放入三種哥布林、獸人、史萊姆及範圍外哥布林。首次放置 15 秒後觸發，其後在 30、45…秒觸發。每次增益光環維持 5 秒，隊長喊叫動作播放 0.75 秒。按暫停會凍結計時。可按「立即預覽戰吼」重啟視覺週期。

目前只做增益動畫：示意半徑 160 素材座標單位（目前世界比例 2×，畫面標示 320 px），不代表最終技能範圍。受增益類別：哥布林、炸彈哥布林、哥布林弓箭手；死亡／逃離或範圍外單位不顯示光環。光環隨當下位置更新，重疊範圍只繪製一次。程式不修改任何移速、攻速、攻擊冷卻、傷害或血量。未新增正式關卡出場／Boss 戰鬥數值。
