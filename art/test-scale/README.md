# 測試區共用關卡比例

`TD.CAMPAIGN_WORLD_SCALE` 是正式三關與 `/test` 共用的戰鬥倍率（2）。測試模擬使用新的獨立 scenario，地圖、道路宽度、建造底座來自 `TD.MAP_CONFIG`；第一、二關既有路線與第二關 80 px 舊道路保持原設定，測試區使用第三關起的 96 px 標準。

怪物固定按世界倍率顯示，箭塔與正式關卡共同使用 `TowerSprites.worldRect`，依 64 px 底座定位。木柵欄共用 `FenceSprites`，保留正式版的顯示長度與碰撞尺寸。石牆仍為測試用俯視美術。地面由正式版 `Environment.makeBackground` 產生，道路位置沿用測試區十字路線；不自動擺放阻礙檢視的樹木。場景素材採用共用佈景程式的一個代表尺寸。

移除個別物件的 1×～4× 倍率控制。畫面縮放提供「符合視窗」、50%、75%、100%、150%、200%。100% 表示一個世界座標像素等於一個 CSS 像素；縮放僅變更 Canvas 顯示大小，不變更 1280×768 世界、物件、射程、移速或模擬時間。放大後可使用容器捲軸／觸控板移動視野，選取與放置座標仍按畫布實際位置換算；縮放亦可於模擬中操作。

炸彈塔基礎射程 55～125 經共用世界倍率換算為 110～250 世界像素，爆炸半徑為 128；顯示圈與模擬一致。

驗證：`node --test tests/test-scale.test.cjs`；`node tools/check-test-scale.cjs` 檢查實際箭塔尺寸、模擬倍率、暫停資料不因縮放改變、捲動後放置、手機版與全螢幕切換。
